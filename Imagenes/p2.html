Imágenes Digitales

Una imagen digital es una representación visual creada a través de medios digitales o capturada con una cámara digital. Está formada por pequeños elementos llamados píxeles (del inglés *picture element*), que son las unidades más pequeñas que componen una imagen digital. Cada píxel almacena información sobre un color y ocupa una posición específica dentro de la imagen.

A continuación, se muestra una imagen en la que se pueden observar diferentes píxeles. En este caso, tiene 28 píxeles de ancho por 32 píxeles de alto, para un total de 896 píxeles que, al organizarse, permiten formar la imagen completa.

¿Alguna vez has querido saber exactamente qué color tiene una imagen? En la imagen de arriba se muestra una herramienta llamada Image Color Picker, que te permite subir cualquier foto y seleccionar un punto específico para descubrir el código exacto del color (como HEX o RGB). Es súper útil si quieres usar esos colores en tus diseños, tareas o redes sociales. Solo tienes que subir tu imagen, hacer clic donde quieras y listo, ¡tienes el color que necesitas!


Modelos de color: RGB, HEX y HSV

🔢 Modelo RGB y representación HEX

RGB es un modelo de color basado en la mezcla de luces: rojo (Red), verde (Green) y azul (Blue). Cada uno puede tener un valor entre 0 y 255. Por ejemplo, R=255, G=0, B=0 es rojo puro.

Esto es muy útil para entender cómo se compone un color y cómo modificarlo desde sus componentes. Se usa en pantallas, celulares, computadoras, etc.

La representación HEX es una forma más corta de escribir los valores RGB en base 16. Por ejemplo, el color #800080 significa:

  • 80 = 128 en rojo
  • 00 = 0 en verde
  • 80 = 128 en azul

Se usa mucho en diseño por la simplicidad al momento de indicar el color (cantidad de digitos), aunque no es tan clara para entender la composición interna del color.

🛠️ Figuras basicas en Inkscape

Una de las figuras más faciles de usar en Inkscape es el rectangulo, el cual se muestra a continuación

En Inkscape, cualquier figura que dibujes, como un rectángulo, un círculo o incluso una letra convertida en forma, se llama objeto. Todos los objetos tienen características que puedes cambiar para personalizarlos.

  • Relleno: Es el color que va dentro del objeto. Puede ser un color sólido, un degradado o incluso transparente.
  • Borde (trazo): Es la línea que rodea al objeto. También puedes cambiar su color, hacerlo más grueso o delgado.
  • Estilo del borde: Se refiere a si el borde es una línea recta, punteada, discontinua, etc.

Puedes modificar estas propiedades desde el menú de la derecha llamado “Relleno y borde”, o presionando Mayús + Ctrl + F.

Explorar estos cambios te permite hacer diseños más creativos y darles un estilo visual que exprese tus ideas.

Agrega varios rectángulos al lienzo y cámbiales el color usando una de estas gamas:

  • Colores cálidos: rojo, naranja, amarillo
  • Colores fríos: azul, verde, violeta
  • Colores tierra: marrón, beige, oliva
  • Colores neón: verde neón, fucsia, cian brillante
  • Colores neutros: blanco, negro, gris
