Variables


Anteriormente aprendimos a utilizar la instrucción print(), que permite mostrar información en la pantalla. Ahora aprenderemos a utilizar las variables, una herramienta fundamental en la programación.

Una variable es un nombre que utilizamos para identificar un dato almacenado en la memoria del computador. Podemos imaginarla como una caja que tiene un nombre y contiene información que el programa puede consultar y utilizar posteriormente.

Por ejemplo, si queremos guardar el nombre de una persona, podemos escribir: 

nombre = "Juan"

En esta instrucción, nombre es el identificador de la variable, el símbolo = es el operador de asignación y "Juan" es el dato que estamos almacenando.

En Python, el operador = se utiliza para asignar un valor a una variable. No significa necesariamente que ambos lados sean iguales como ocurre en una operación matemática.

1. ¿Para qué sirven las variables?

Las variables permiten guardar información para utilizarla en diferentes partes de un programa. Esto evita tener que escribir nuevamente un dato cada vez que necesitamos utilizarlo.

Observemos la diferencia entre mostrar un mensaje directamente y utilizar una variable.

Sin utilizar variables:

print("Hola Juan")

El programa muestra el mensaje Hola Juan. Sin embargo, si queremos cambiar el nombre, debemos modificar el texto escrito dentro de la instrucción.

Utilizando una variable:

nombre = "Juan"
print("Hola", nombre)

El resultado será: 

Hola Juan

En este caso, la instrucción print() muestra el texto "Hola" y luego el valor almacenado en la variable nombre.

Si cambiamos la primera línea por nombre = "María", el resultado será Hola María, sin necesidad de modificar la instrucción print().

2. Variables que almacenan texto

Cuando necesitamos almacenar palabras, nombres o frases, utilizamos variables que contienen texto. En Python, estos datos se conocen como cadenas de caracteres y se escriben entre comillas. 

nombre = "Juan"
mensaje = "Hola, " + nombre + "!"

print(mensaje)

El resultado será: 

Hola, Juan!

En este ejemplo, el símbolo + permite unir dos cadenas de texto. Esta operación se conoce como concatenación.

También podemos utilizar comas dentro de print() para mostrar diferentes datos: 

nombre = "Juan"
print("Hola", nombre)

Es importante recordar que las comillas se utilizan para escribir un texto directamente, mientras que una variable se escribe sin comillas cuando queremos consultar el valor que contiene.

3. Variables que almacenan números

Las variables también pueden almacenar números. Estos datos pueden utilizarse para realizar operaciones matemáticas. 

edad = 14
altura = 1.65

print("Edad:", edad)
print("Altura:", altura)

En este ejemplo, edad almacena un número entero y altura almacena un número decimal.

Python reconoce automáticamente el tipo de dato según el valor asignado. No es necesario escribir la palabra float para guardar un decimal.

Podemos utilizar estas variables para realizar operaciones: 

edad = 14
edad_futura = edad + 5

print("Edad actual:", edad)
print("Edad dentro de cinco años:", edad_futura)

El programa calcula un nuevo valor utilizando la información almacenada en la variable edad.

4. Tipos de datos básicos

Las variables pueden almacenar diferentes tipos de datos. Algunos de los más utilizados en Python son:

  • Texto (str): almacena nombres, palabras o frases. Ejemplo: nombre = "Juan".
  • Entero (int): almacena números sin parte decimal. Ejemplo: edad = 14.
  • Decimal (float): almacena números con parte decimal. Ejemplo: altura = 1.65.
  • Booleano (bool): almacena uno de dos valores: True o False. Ejemplo: encendido = True.

Observa estos dos ejemplos: 

edad = 14
numero = "14"

Aunque parecen similares, sus tipos de datos son diferentes. La variable edad almacena un número entero, mientras que numero almacena el texto "14".

Por esta razón, es importante reconocer qué tipo de información contiene cada variable.

5. Reglas para nombrar variables

Para crear variables, debemos utilizar nombres que permitan identificar fácilmente la información que almacenan.

  • El nombre puede contener letras, números y guiones bajos.
  • No puede comenzar con un número.
  • No debe contener espacios.
  • Python distingue entre mayúsculas y minúsculas. Por ejemplo, nombre y Nombre son variables diferentes.
  • Es recomendable utilizar nombres descriptivos, como edad, temperatura o nombre_estudiante.

Ejemplos de nombres válidos: 

nombre = "Laura"
edad2 = 15
temperatura_actual = 24.5

Ejemplos de nombres no válidos: 

2edad = 15
nombre estudiante = "Laura"

Los ejemplos anteriores presentan errores porque el nombre de una variable no puede comenzar con un número ni contener espacios.

Conclusión

Las variables son fundamentales en programación porque permiten almacenar y reutilizar información durante la ejecución de un programa.

Mientras print() permite mostrar información en la pantalla, las variables permiten identificar y consultar los datos que necesitamos utilizar. Al combinar ambas herramientas, podemos crear programas más flexibles y fáciles de modificar.
