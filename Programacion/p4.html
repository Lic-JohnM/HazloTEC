Print


Ahora que conoces algunas de las características de Python, es importante entender cómo mostrar información en la pantalla. Una de las instrucciones básicas es print(), que permite presentar mensajes, resultados de operaciones y datos almacenados en variables.

Por ejemplo:

print("¡Hola, mundo!")
print("Python es divertido.")
print("Este es un ejemplo de print.")

Cada instrucción print() muestra un mensaje en la pantalla. Puedes experimentar con estos ejemplos en Google Colab, una herramienta en línea donde puedes ejecutar código Python directamente desde tu navegador. Haz clic en el siguiente enlace para probarlo: Google Colab.

Concatenación de textos


En programación, la concatenación consiste en unir dos o más cadenas de texto para formar una sola. En Python, podemos realizar esta operación utilizando el símbolo +.

Imagina que tenemos dos textos independientes y queremos unirlos para formar un mensaje completo. 

print("Hola, " + "mundo")

El resultado será:

Hola, mundo

Python une ambos textos en el orden en que aparecen. Observa que el primer texto contiene un espacio después de la coma. Si no lo escribimos, las palabras quedarían pegadas.

También podemos concatenar textos que están almacenados en variables: 

nombre = "Juan"
saludo = "Hola, " + nombre

print(saludo)

El resultado será:

Hola, Juan

En este ejemplo, Python toma el texto almacenado en la variable nombre y lo une con el texto "Hola, ". El resultado de esa unión se guarda en la variable saludo.

La ventaja es que podemos cambiar el valor de nombre y obtener un saludo diferente sin tener que escribir nuevamente todo el mensaje. 

nombre = "María"
saludo = "Hola, " + nombre

print(saludo)

Ahora el resultado será:

Hola, María

Concatenación con variables


Podemos unir varias variables para construir mensajes más completos. Por ejemplo: 

nombre = "Laura"
apellido = "Gómez"

nombre_completo = nombre + " " + apellido

print(nombre_completo)

El resultado será:

Laura Gómez

Observa que utilizamos " " para agregar un espacio entre el nombre y el apellido. Este espacio también es una cadena de texto y forma parte de la concatenación.

Importante: el operador + permite concatenar cadenas de texto, pero no podemos unir directamente una cadena con un número. 

edad = 15

# Esta instrucción genera un error:
# print("Tengo " + edad + " años")

Para solucionarlo, podemos convertir el número en texto utilizando str(): 

edad = 15

print("Tengo " + str(edad) + " años")

El resultado será:

Tengo 15 años

¿Es lo mismo concatenar que utilizar comas en print()?


No exactamente. Aunque ambas formas permiten mostrar un mensaje con diferentes partes, funcionan de manera distinta.

Utilizando el símbolo +:

nombre = "Juan"

print("Hola, " + nombre)

Python une las cadenas de texto antes de mostrarlas. Si queremos concatenar un número, debemos convertirlo en texto.

Utilizando comas:

nombre = "Juan"
edad = 15

print("Hola, ", nombre)
print("Tu edad es:", edad)

En este caso, print() recibe varios argumentos separados por comas y los muestra en la misma línea de salida. De forma predeterminada, agrega un espacio entre ellos. Además, puede mostrar números sin que tengamos que convertirlos en texto.

Recuerda: + une cadenas de texto, mientras que las comas permiten mostrar diferentes valores dentro de una misma instrucción print().

Tipos de comentarios


Los comentarios permiten escribir explicaciones dentro del código para que las personas puedan comprenderlo con mayor facilidad. Python no ejecuta el contenido de un comentario de línea.

Comentarios de línea: comienzan con el símbolo # y pueden utilizarse para explicar una instrucción o agregar una observación. 

# Este mensaje saluda al usuario
print("Hola, mundo!")

También podemos escribir un comentario al final de una instrucción: 

print("Hola, mundo!")  # Muestra un saludo

Notas de varias líneas: podemos utilizar comentarios con # en varias líneas. También existen las cadenas multilínea, delimitadas por tres comillas, que se utilizan frecuentemente para documentar funciones, clases y módulos mediante cadenas de documentación. 

# Este programa realiza una suma.
# Después muestra el resultado
# mediante la instrucción print().

a = 5
b = 3
resultado = a + b

print("La suma es:", resultado)

En Python, escribir tres comillas no convierte automáticamente el contenido en un comentario. Las cadenas multilínea son textos y su función depende del lugar donde se utilicen.
